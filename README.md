# 5-Stop-Watch
# ⏱️ Stopwatch

A simple and responsive **Stopwatch Web App** built using **HTML, CSS, and JavaScript**. The app allows users to start, pause, and reset the stopwatch with an easy-to-use interface.

## ✨ Features

* ▶️ Start the stopwatch
* ⏸️ Pause the stopwatch
* 🔄 Reset the stopwatch
* ⏱️ Real-time time tracking
* 📱 Fully responsive design
* 🎨 Clean and modern UI
* ⚡ Fast and interactive

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
